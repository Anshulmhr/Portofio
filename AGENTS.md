# Portfolio workflow

Canonical repository: https://github.com/Anshulmhr/Portofio
Canonical branch: main

For every website modification, start from the latest remote main. Preserve existing work and do not force-push. Make only requested changes, test them, run npm run build and npm test, then commit completed work with a clear message and push it to this repository. Do not leave newer work only in a temporary workspace or on chatgpt.site. Report any push blocker explicitly.

Preserve the approved garden-only opening with the initially locked gate, automatic scroll-driven gate opening, and subsequent Anshul Mehra reveal. Do not redesign or reinterpret this experience without a user request. Respect reduced-motion preferences and the existing semantic reading fallback.

No secrets or private environment-specific values may be committed. Keep optional environment variable names documented in .env.example. The current editorial preview/noindex behavior and release content validation remain intentional. A migration alone does not authorize changing them or starting another design phase.
